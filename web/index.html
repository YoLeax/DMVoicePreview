ABOUT THIS LIBRARY

让挑选声音简单一点。

DM Voice 整理了火山引擎音色库的官方试听示例，方便你快速筛选和对比。无需登录，选一个声音就能试听。

收藏喜欢的音色

收藏保存在当前浏览器，刷新后依然保留。不同设备之间不会同步。

复制音色 ID

卡片底部可一键复制 ID；点击名称查看详细信息，也能分享指定音色。

关于试听版本

部分音色有多个语言示例，因此试听记录数与独立音色 ID 数不同。标签表示音色能力，播放的是固定官方示例。
